HTML 是什么？

一段写给"完全没碰过代码"的朋友的入门手册。你不需要装任何软件，
往下翻，所见即所得。

1. 一句话解释

HTML 全称 HyperText Markup Language（超文本标记语言）， 是浏览器能"读懂"的、用来描述网页长什么样的一种文件格式。

你此刻正在看的这个网页，它本身就是一个 HTML 文件。

2. 一个生动的比喻

🏠

把 HTML 想成一栋毛坯房的施工图

施工图上写着："这里放一扇门，那里开一扇窗，客厅 30 平米，朝南"。 它不负责装修（那是 CSS 的活），不负责家电（那是 JS 的活）， 它只负责告诉工人：这栋楼有哪些部分、各部分叫什么、放在哪儿。

浏览器（比如 Chrome）就是那位"工人"，它照着 HTML 这张施工图，
把文字、图片、按钮一块一块地"盖"在屏幕上。

3. 拆开一个 HTML 文件

新建任意一个记事本文件，输入下面这段，保存为 hello.html，双击就能在浏览器打开：

<!DOCTYPE html> <!-- 告诉浏览器：这是 HTML5 --> <html> <head> <meta charset="UTF-8"> <!-- 字符编码 --> <title>我的第一个网页</title> <!-- 浏览器标签页的标题 --> </head> <body> <h1>你好，世界！</h1> <!-- 一级标题 --> <p>这是我写的第一段话。</p> <!-- 一段文字 --> </body> </html>

代码和效果对比

HTML 源码
<h1>你好，世界！</h1>
<p>这是我写的第一段话。</p>
浏览器渲染

你好，世界！

这是我写的第一段话。

4. 什么叫"标签"？

HTML 的核心就是标签（tag）。它长这样：

<标签名>内容</标签名>

绝大多数标签都是成对出现的：开头一个、结尾一个（结尾多一个斜杠 /），
把"内容"夹在中间。少数几个标签是"自闭合"的，比如图片 <img>、换行 <br>。

最常见的 10 个标签

<h1> ~ <h6> 标题（一到六级）
<p> 段落
<a> 链接（跳转）
<img> 图片
<ul> <li> 无序列表
<ol> <li> 有序列表
<div> 通用容器（块）
<span> 通用容器（行内）
<button> 按钮
<input> 输入框

5. HTML、CSS、JS 是什么关系？

一个完整的网页通常由三种语言分工合作：

📄 HTML —— 骨架

页面上有什么内容、是什么结构（标题、段落、图片、按钮……）。

🎨 CSS —— 皮肤

长什么样（颜色、字体、间距、动画、响应式布局……）。

⚙️ JavaScript —— 神经

会做什么（点击按钮弹出菜单、表单校验、加载数据……）。

这页文件 就同时包含了这三者，所以你看到的样子是三件事一起作用的结果。

7. 怎么"运行"一个 HTML？

  1. 在桌面右键 → 新建文本文档 → 改名为 test.html（注意改后缀）。
    ⚠️ Windows 默认会把扩展名藏起来，改完很可能其实是 test.html.txt，双击根本打不开。先在文件资源管理器顶部 「查看」 里勾上 「文件扩展名」，才能真的改对后缀。
  2. 右键 → 用记事本打开 → 粘入上面的代码 → 保存
  3. 双击这个文件 → 它会用你的默认浏览器打开
  4. 成了。这就是你写的第一个网页。

不需要装任何东西。Windows、macOS、Linux 自带就能跑。
