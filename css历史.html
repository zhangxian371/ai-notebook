CSS 的诞生

一段关于"失控与修复"的网页史。
如果说 HTML 解决"内容如何组织"、HTTP 解决"内容如何获取"，那 CSS 解决的是——内容如何呈现。

1. 一句话定位

HTML

信息如何组织
Structure · 结构

HTTP

信息如何获取
Transport · 传输

CSS

信息如何呈现
Presentation · 表现

三个完全不同的问题，三种不同的解决方案。
Web 的"三层职责"就是这样来的。

2. 最初，HTML 只想让科学家共享文档

1991 年，Tim Berners-Lee 设计 HTML 时，目标非常明确：

让科学家共享文档，不是设计漂亮网页。

所以早期 HTML 标签长这样：

<h1>标题</h1> <p>正文</p> <ul> <li>项目</li> </ul>

全都是 结构、结构、结构。没有颜色、没有字体、没有动画、没有布局。
在 Tim 看来：文档内容比外观重要。

📝

这其实和你前面接触的 Markdown 非常像

Markdown 用 # 标题 表示"这是标题"，但不规定"标题应该多大、用什么颜色"。
早期 HTML 也是这样：只描述这是什么，不描述长什么样。

3. 失控的年代：1993 ~ 1995

Web 开始爆发。越来越多人开始做网站。
大家突然发现：所有网页长得都差不多。

🖤 默认长这样

黑字、白底、蓝色链接。
非常丑，但大家都一样。

商业公司开始提需求：

  • "我要红色标题"
  • "我要更大的字体"
  • "我要符合品牌风格"

但 HTML 没有这些能力。

4. 灾难：浏览器厂商开始往 HTML 里塞样式

既然 HTML 没有样式能力，那就给它加上——于是各种"展示型标签"出现了：

那时候的 HTML

        face="Arial">

HTML 的职责被污染了：

⚠️ 原本的分工

HTML = 描述文档结构

❌ 实际上变成了

HTML = 结构 + 样式

这违反了一个重要原则：Separation of Concerns（关注点分离）。

5. 1994 年，一位挪威程序员出手了

1994 挪威程序员 Håkon Wium Lie 提出 Cascading Style Sheets（层叠样式表），简称 CSS。
1996 CSS 1 正式成为 W3C 推荐标准。
1998 CSS 2 发布，加入定位、媒体类型等。
2011 CSS 3 拆分模块，按节奏逐步发布（圆角、阴影、动画……）。

核心思想极其简单：

💡 一句话

不要往 HTML 里塞样式。把样式单独放出去。

HTML（只管结构）
<h1>Hello</h1>
CSS（只管长相）
h1 {
  color: red;
  font-size: 40px;
}

各管各的，干净。

6. CSS 真正解决的三件事

6.1 内容与表现分离

以前要改 1000 个页面的颜色，得改 1000 次。现在改 1 个 CSS 文件就够了。

📦 带来的好处

同一个 HTML 配不同的 CSS = 完全不同的视觉风格。
这就是后来 主题切换 / 深色模式 的雏形。

6.2 网站第一次有了"主题"

HTML 保持不变，切换不同 CSS 文件就能换皮肤——数据 + 皮肤分离。

6.3 解决布局问题

网站越来越复杂：导航栏、侧边栏、广告位、内容区……HTML 不知道怎么安排位置。
于是 CSS 逐渐发展出布局能力：

  • Float —— 最古老，浮动布局
  • Position —— 定位（相对、绝对、固定）
  • Flexbox —— 一维布局（行或列）
  • Grid —— 二维布局（行 × 列）

7. 三大经典职责的总结

HTML

内容是什么
Structure 结构

HTTP

内容怎么拿过来
Transport 传输

CSS

内容长什么样
Presentation 表现

这三条加在一起，才让 Web 从科研文档系统变成了今天的互联网。

9. 拆解名字：Cascading Style Sheets

中文叫层叠样式表，但"层叠"对初学者不太直观，拆开看就懂了。

9.1 Style Sheets（样式表）

"样式表"很好理解——一组描述外观的规则，合在一起就是一张表：

h1 { color: red; } p { font-size: 16px; } .box { padding: 20px; } // 一堆规则放在一起 = 一张样式表

9.2 Cascading（层叠）—— CSS 真正在强调的事

当多个样式同时作用于同一个元素，浏览器会按一套规则决定最终用哪个。这个过程叫 cascade（层叠）。

10. 层叠的底层：优先级（Specificity）

CSS 名字里真正强调的不是颜色、不是字体，是"层叠"——也就是冲突时谁赢。

公司里的"层叠"长这样

公司规定：所有员工穿白衬衫（最低优先级）
部门规定：技术部穿黑衬衫（类选择器）
老板特别要求：张三今天穿红衬衫（ID 选择器）
张三在衣服上贴张条：必须红色（行内样式）
最终：张三穿红衬衫

所以学 CSS 学到后面，核心其实就 4 件事：

  • 继承（Inheritance）—— 子元素自动继承父元素的某些样式
  • 层叠（Cascade）—— 多条规则如何合并
  • 优先级（Specificity）—— 谁更"具体"谁赢
  • 覆盖（Override）—— 后写的可以覆盖先写的

理解了这套规则，颜色和字体只是"顺手记住"的属性而已。

11. 一句话回顾

🎨 CSS = 一套给 HTML 描述外观的规则系统

它的核心不是"颜色、字体、布局"，而是按层叠规则进行合并和覆盖的样式表。
